Quick start

One API call

curl -X POST https://docstruct.marwannaili-23-07.workers.dev/v1/extract \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Harbor Trading INVOICE #INV-2026-1901 Date: 08/02/2026 ...",
    "type": "invoice",
    "output": "json"
  }'

# → { "ok": true, "data": { "vendor": {...}, "number": "INV-2026-1901", ... } }
